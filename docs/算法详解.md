# BsLocator 联合估计算法详解

> 本文档详细描述 BsLocator 的基站位置与天线方向图联合估计算法，
> 与代码实现一一对应：`app/app/src/main/java/com/example/bslocator/algorithm/BaseStationEstimator.kt`
> （下文引用行号以该文件为准）。

## 1. 问题形式化

给定某个小区（以 ECI 唯一标识）的 N 条路测记录，每条包含 GPS 位置 (latᵢ, lngᵢ)
与实测 RSRP 值 yᵢ，求解使预测 RSRP 与实测值误差最小的 8 维参数向量：

```
θ = [bsX, bsY, azimuth, beamwidth, tilt, bsHeight, n, p0]
      │    │      │        │         │      │       │   └ 1 米参考电平 (dBm)
      │    │      │        │         │      │       └ 路径损耗指数
      │    │      │        │         │      └ 基站挂高 (m)
      │    │      │        │         └ 电子下倾角 (°)
      │    │      │        └ 水平 3dB 波束宽度 (°)
      │    │      └ 天线方位角（主瓣指向，°，北为 0 顺时针）
      │    └ 基站位置（ENU 局部坐标，m）
      └ 基站位置
```

## 2. 信号模型

### 2.1 坐标系

所有经纬度先转换为以第一个有效测量点为原点的 ENU 局部平面坐标（`latToNorth` /
`lngToEast`，`:512-516`），避免在球面上做优化：

```
north = (lat − lat₀) · π/180 · R
east  = (lng − lng₀) · π/180 · R · cos(lat₀)     R = 6371000 m
```

估计完成后再转回 WGS-84（`:94-95`）。

### 2.2 预测 RSRP（`predictedRssi`，`:260`）

```
RSRP_pred = PL(d) + A(Δφ, el)
```

**路径损耗**（对数距离模型）：

```
PL(d) = p0 − 10 · n · log10(d)        d = √(Δx² + Δy²)，下限截断为 1 m
```

**天线方向图增益**（基于 3GPP TR 38.901 宏基站模型，硬截断/平滑饱和**两种模式可选**，`antennaGain3GPP`）：

```
模式 A（默认，3GPP 原始模型）：
  A_H(Δφ) = −min[12 · (Δφ / φ₃dB)², 30 dB]
  A_V(el) = −min[12 · ((el + tilt) / 10°)², 30 dB]

模式 B（平滑饱和，近基站采样更优）：
  A_H(Δφ) = −A_m · tanh( 12 · (Δφ / φ₃dB)² / A_m )
  A_V(el) = −A_m · tanh( 12 · ((el + tilt) / 10°)² / A_m )     A_m = 30 dB

前后比：|Δφ| > 90° 时额外 −25 dB
总增益：A = A_H + A_V + FBR
```

其中：
- Δφ = 测量点相对方位 − 天线方位角（归一化到 ±180°）
- el = atan2(bsHeight − 1.5 m, d) 为俯仰角（UE 高度固定取 1.5 m）
- 垂直面 3dB 波束宽度固定为 10°（`V_BEAMWIDTH`，固定理由见第 7 节与附录 A 之后的实验）
- 模式在推断页由用户选择（持久化到 SharedPreferences），通过 WorkManager inputData
  传给 Worker，`BaseStationEstimator.PatternCap` 枚举实现

**两种模式的差异与实测结论**：3GPP 硬截断在截断区梯度恒为零，落在其中的测量点
（典型：离基站很近、俯仰角很大的点，如 7m 处俯仰角 77°）对 tilt、波束宽度、挂高等
参数完全失去梯度信息；tanh 平滑饱和主瓣区与 3GPP 完全一致、大角度平滑逼近同一个
30dB 地板（实测旁瓣包络 28~30 dB）且梯度处处非零。44 个真实小区 A/B 对比实验：
总体拟合与交叉验证打平，含近距点的小区 B 的交叉验证明显改善（典型 6.68→4.53 dB），
但绝对位置的稳定性 A 整体更可靠（基于带地图底图的位置对比人工判读）。
**因此默认 A，近基站采样丰富时用户可手动切 B。**

### 2.3 模型参数边界

优化全程在盒约束内进行（投影梯度，`:172-181`）：

| 参数 | 下界 | 上界 | 说明 |
|---|---|---|---|
| bsX, bsY | min(点集)−500m | max(点集)+500m | 限制在测量范围附近 |
| azimuth | 0° | 360° | |
| beamwidth | 30° | 120° | 宏站典型 3dB 波束宽度 |
| tilt | 0° | 15° | 电子下倾角常见范围 |
| bsHeight | 5 m | 50 m | |
| n | 1.5 | 5.0 | 自由空间 2，密集城区 4+ |
| p0 | −80 dBm | −20 dBm | |

## 3. 数据预处理

- **GPS 精度过滤**：丢弃精度 > 15 m 的点（`MAX_GPS_ACCURACY`，`:53`），
  防止位置噪声被模型当作"假衰落"吸收
- **最少样本数**：过滤后不足 10 条（`MIN_MEASUREMENTS`）直接返回失败
- **ECI 分组**：不同小区（扇区）的测量严格分开估计，避免方向图混淆

## 4. 损失函数：Huber 鲁棒损失

最小化所有测量点的 Huber 损失之和（`huberLoss`，`:475`）：

```
              ┌ ½·r²                |r| ≤ δ
L(r) =        │
              └ δ·(|r| − ½δ)        |r| > δ        δ = 5 dB
```

残差 r = RSRP_pred − RSRP_meas。δ = 5 dB 的选取依据：实测拟合 RMSE 约 4~5 dB
（城市环境阴影衰落标准差典型 6~10 dB 的下半区），即"正常点基本落在二次区，
深衰落 / NLOS 异常点落入线性区"。

**等价解释**：Huber 是 IRLS（迭代重加权）的特例，等价于给每个点赋权
wᵢ = min(1, δ/|rᵢ|)——残差越大的点话语权越小，但不为零（软降权）。

## 5. 优化器：投影梯度 + Armijo 回溯

不用通用数值优化库，而是手写带解析梯度的投影梯度下降（`optimize`，`:171`）：

1. **解析梯度**：8 个参数对损失的偏导全部手推（`computeLossAndGrad`，`:337`），
   包括方向图增益对 (bsX, bsY) 经由相对方位角/俯仰角的链式求导；
   方向图采用 tanh 平滑饱和后梯度处处非零（sech² 因子），无截断盲区。
   **完整公式推导见附录 A**
2. **Armijo 回溯线搜索**：初始步长 α=1，每次减半（最多 20 次），直到满足
   `L(θ+αd) ≤ L(θ) + 1e-4·α·∇Lᵀd`（`:218-231`）
3. **投影**：每次试步后把参数钳回盒约束区间
4. **收敛判据**：投影梯度范数 < 1e-6，或达到 500 次迭代上限
5. **兜底**：线搜索失败时退化为 0.001 固定步长，保证迭代不死锁

复杂度：每次迭代 O(N)，单次推断实测约数千次迭代、秒级完成（真机实测
7507 次迭代计数包含线搜索试探）。

## 6. 多起点策略

目标函数非凸（方向图项引入大量局部最优），单起点不可靠。生成 4 组差异化的
初始猜测（`generateInitialGuesses`，`:114`），各自独立优化，取 RMSE 最小者：

| # | 初始位置 | 思路 |
|---|---|---|
| 1 | 信号强度线性加权质心 | 强信号点大概率离基站近 |
| 2 | 最强信号点本身 | 覆盖"基站就在热点旁"的情形 |
| 3 | 包围盒几何中心 | 不依赖信号强度的中性猜测 |
| 4 | 反距离加权质心 | 与 #1 互补，防漏远点信息 |

所有起点的初始方位角统一取"候选位置指向最弱信号点的方向"
（`guessAzimuth`，`:161`——背瓣最弱，主瓣在其反方向附近，给优化器一个
大致正确的 basin），其余参数固定初值：beamwidth=65°，tilt=6°，
bsHeight=30m，n=3.0，p0=−40 dBm。

## 7. 对阴影衰落与 LOS/NLOS 的处理

算法**不显式建模**这两类效应，而是通过组合手段抵抗（详细讨论见研究报告 5.2 节）：

| 手段 | 对抗的问题 | 代码位置 |
|---|---|---|
| Huber δ=5dB | 阴影衰落波动、NLOS 离群点 | `:475` |
| n、p0 自由拟合 | LOS/NLOS 混合造成的平均衰减差异 | `:172` |
| 方向图 tanh 平滑饱和（30dB 地板） | 旁瓣区模型失配制造极端残差，且保留大角度梯度信息 | `:303` |
| GPS 精度过滤 | 位置噪声伪装成衰落 | `:53` |
| 多起点取最优 | 异常点簇诱导的局部最优 | `:114` |

**已知局限**：
- 无逐点 LOS/NLOS 分类（无双状态路损模型）
- 阴影衰落的空间相关性未利用（视为独立同分布残差）
- 反射主导型 NLOS（街道峡谷）下几何关系被破坏，会产生不可恢复的系统偏差
  ——单基站单 RSRP 观测量在信息论层面无法区分直射与镜像反射

## 8. 精度优化工程全景（Optimization Toolbox）

最终的定位精度不是某一个算法决定的，而是一系列针对性优化的叠加——每一项
消除一个明确的误差源。下表是总览，随后逐条详述做法与依据。

| # | 优化项 | 针对的误差源 | 机制 |
|---|---|---|---|
| 1 | 联合估计（核心思想） | 天线方向图未知 | 位置与方向图参数同时反演 |
| 2 | Huber 鲁棒损失（δ=5dB） | 阴影衰落、NLOS 离群点 | 大残差点影响力封顶 |
| 3 | 解析梯度 | 端上算力限制 | 8 参数闭式偏导（附录 A） |
| 4 | 4 组多起点 | 非凸局部最优 | 差异化初值，RMSE 最优者胜 |
| 5 | 盒约束投影梯度 | 物理不可能的参数漂移 | 每步投影回先验区间 |
| 6 | Armijo 回溯 | 方向图不可微折点 | 保证损失单调不增 |
| 7 | GPS 精度过滤 | 位置噪声伪装成衰落 | 剔除精度 >15m 的点 |
| 8 | ECI 分组（而非 PCI） | 扇区数据混淆 | PCI 会碰撞，ECI 全局唯一 |
| 9 | 三通道采集 | 采样稀疏 | GPS + 回调 + 兜底轮询 |
| 10 | ENU 局部坐标 | 数值条件 | 米制局部平面，非经纬度 |
| 11 | 垂直波宽固定 10° | 不可辨识参数 | 固定先验=正则化（A/B 验证） |
| 12 | 方向图截断 A/B 可选 | 近距点梯度死亡 | tanh 平滑饱和，用户可选 |

### 1. 联合估计：最大的那一步（350m+ → 8~15m）

**问题**：忽略方向图的定位误差 350m+，比随机猜测还差；而现实中方向图参数
（方位角、波束宽度、下倾角）几乎总是未知的。
**做法**：把方向图参数和基站位置放进同一个 8 维参数向量，用同一个物理模型
（对数路损 + 3GPP 方向图）对全部测量点做联合优化（第 2~5 节）。
**依据**：全向覆盖仿真误差 8.2m、方位角 0.8°；与"方向图已知"方法同档（第 3 节
实验、研究报告第 6 节对比表）。

### 2. Huber 损失：按物理标定的鲁棒性

**问题**：阴影衰落（σ≈6~10dB）和 NLOS（额外 10~30dB）让最小二乘被少数深衰落
点带偏。
**做法**：Huber δ=5dB——δ 不是拍脑袋，是实测 LOS 主导路线的拟合 RMSE 下限
（4~5dB）：正常点保持二次型影响力，超出 5dB 的点线性降权。等价于 IRLS 权重
wᵢ=min(1, δ/|rᵢ|)。
**依据**：实测 RMSE 4.95dB，正好是设计工作点。

### 3. 解析梯度：不是奢侈品，是能跑起来的前提

**问题**：数值微分下单次推断要几分钟，多起点和批量推断无从谈起。
**做法**：8 个参数的偏导全部手推（附录 A），含方向图经由方位角/俯仰角对位置
的链式求导；与中心差分交叉验证。
**效果**：单次推断分钟级→秒级，端上批量 100+ 小区成为可能。

### 4. 四组多起点：最便宜的局部最优解药

**问题**：方向图项让目标函数非凸，旋转个方位角就可能造出一个"看起来不错"
的局部最优。
**做法**：RSRP 加权质心、最强信号点、包围盒中心、反距离加权质心四组初值，
方位角统一指向**最弱点**（背瓣是数据里最尖锐的角度地标），各自完整优化后
取 RMSE 最小者。成本仅 4 倍，单侧轨迹下常常是成败之别。

### 5~6. 盒约束 + Armijo：把优化器关在物理世界里

**做法**：所有参数限制在物理先验区间（波宽 30~120°、下倾 0~15°、挂高 5~50m、
n∈[1.5,5]、站址在测量范围 ±500m 内），每步投影回盒内；Armijo 回溯保证即使
跨过方向图不可微折点，损失也单调不增，优化器永不发散。

### 7. GPS 精度过滤：位置噪声 ≠ 衰落

**问题**：30m 误差的 GPS 定位点会让模型看到"幻影衰减"，是步行路测最大的
系统性偏差源。
**做法**：采集时丢弃精度 >20m 的点，估计前再过滤 >15m 的点。

### 8. ECI 分组：数据卫生

**问题**：PCI 每隔几百米就重复，按 PCI 分组会把不同基站不同扇区的测量混成
一个"幽灵天线"。
**做法**：全链路以 ECI（全局唯一）分组，PCI 仅用于显示。

### 9~10. 采集密度与数值基础

**做法**：GPS 更新（500ms）+ 信号变化回调 + 2s 兜底轮询三通道融合，先到先用，
绝不丢拍（覆盖度是可辨识性的生命线，见仿真实验）；估计在 ENU 局部平面坐标
（米制）中进行，避免经纬度直接优化的数值病态。

### 11. 垂直波宽固定 10°：经过实验验证的正则化

**问题**：把垂直 3dB 波宽也放开看似白捡精度，实测反而有害。
**做法/依据**：44 个真实小区 A/B 实验：自适应版本交叉验证 RMSE 变差、位置/
方位角漂移均值 87m/41°——tilt（平移）与波宽（缩放）在行人俯仰角窗口内形成
平坦退化山谷。固定 10°（宏站典型 5~15° 中值）不是简化，是正则化
（第 7 节 Discussion 有完整实验）。

### 12. 方向图截断 A/B 可选：复活近距点的梯度

**问题**：3GPP 硬截断区梯度为零，近基站高俯仰角点（如 7m 处 77°）全部失效。
**做法**：提供 A（硬截断，默认）/ B（tanh 平滑饱和）双模式。B 的主瓣区与
3GPP 完全一致、平滑逼近实测存在的 30dB 旁瓣地板、梯度处处非零。
**依据**：44 小区 A/B：总体打平、含近距点小区 B 的交叉验证明显改善
（6.68→4.53dB）、绝对位置 A 更稳定——故默认 A，近距采样丰富时用户可切 B
（第 2.2 节）。

## 9. 未来改进方向

### 9.1 已在 44 个真实小区上评估过（2026-09，7395 条实测数据）

评估协议：基线 = 8 参数 + 硬截断 + Huber（CV RMSE 均值 6.69dB）；split-half
交叉验证 + 参数稳定性（半折位置差）。脚本见 `analysis/opt*.py`，
明细在 `_archive/opt_summary.csv`。

| 候选优化 | 结果 | 判定 |
|---|---|---|
| 静止段去重/降权 | 全体中性（胜率 12/44）；但静止占比 >30% 且 n>150 的小区 CV 6.62→6.14，半折位置稳定性 133.6m→59.3m | **条件采纳**：仅对高静止占比小区启用 |
| 空间分箱 + 线性域平均 | CV 中性偏负（胜率 20~22/44），且网格原点相位引入 43~61m 位置抖动 | **不采纳** |
| IRLS 两轮拟合（剔 >10dB 残差） | CV 6.69→6.84 变差，两轮间位置跳变均值 133m——Huber 已压制离群点，>10dB 残差主要是模型失配而非野值 | **不采纳** |
| SINR/RSRQ 预筛 NLOS | 假设被数据证伪：Spearman(|残差|, SINR)=+0.114（方向反了：低 SINR 点残差反而小），RSRQ 完全无关（ρ=0.008） | **不采纳** |

重要推论：基线的 CV（6.69）与样本内 RMSE（5.96）差距不大，说明当前模型
过拟合有限，**提升空间主要在数据质量（NLOS/多径）而非拟合技巧**。

### 9.2 待评估/待实现（按性价比排序）

1. **人体遮挡建模（IMU 航向）**：人体对 3.5GHz 遮挡 2~10dB 且有方向性——用
   陀螺仪/磁力计航向角与基站相对方位构造遮挡项 loss_body = A·max(0, cos Δθ)，
   仅增加 1 个参数即可把"背对/面对基站"的同距离 RSRP 差异从噪声变成可解释项
2. **TA（Timing Advance）采集与距离软约束**：1 个 TA 步进 ≈ 78m，不受衰落影响，
   NLOS 下偏差有界，可作为 RSRP 之外的独立距离锚点（需先验证机型支持）
3. **多基站联合定位**：利用邻小区交叉观测平均掉反射偏差
4. **EM 双状态模型**：每点引入 LOS/NLOS 隐变量，交替估计标签与参数（参数翻倍，
   当前覆盖条件下大概率不可辨识，研究向）
5. **GPR 残差修正**：仅对阴影衰落的空间相关场有效（方向图是相对方位函数，
   GPR 学不了，见研究报告 1.1 节），对定位精度提升有限，优先级最低

## 附录 A：解析梯度的完整推导

> 对应代码 `computeLossAndGrad`（`BaseStationEstimator.kt:337`）。
> 以下对单个测量点推导，总梯度为各点之和。记号与代码变量名保持一致。

### A.1 符号与中间变量

对测量点 $(e_i, n_i)$（ENU 坐标）和参数向量
$\theta = [b_x, b_y, \phi, \phi_{bw}, \tau, h, n, p_0]$：

$$
\Delta x = e_i - b_x,\qquad \Delta y = n_i - b_y,\qquad d = \sqrt{\Delta x^2 + \Delta y^2}
$$

方位角与俯仰角（单位：度，$\kappa = 180/\pi$ 为弧度→度换算系数）：

$$
\beta = \kappa \cdot \mathrm{atan2}(\Delta x, \Delta y)
\quad\text{（测量点相对基站的方位，北为 0°）}
$$

$$
\Delta\varphi = \mathrm{wrap}_{180}\big(\beta - \phi\big)
\quad\text{（相对主瓣的偏航角）}
$$

$$
\psi = \kappa \cdot \mathrm{atan2}(h - 1.5,\ d)
\quad\text{（俯仰角，UE 高 1.5 m）},\qquad
\Delta\psi = \psi + \tau
$$

预测电平：

$$
\hat{y} = \underbrace{p_0 - 10\, n \log_{10} d}_{PL(d)}
\;\underbrace{-\min\!\Big[12\Big(\tfrac{\Delta\varphi}{\phi_{bw}}\Big)^{\!2},\ 30\Big]}_{A_H}
\;\underbrace{-\min\!\Big[12\Big(\tfrac{\Delta\psi}{10^{\circ}}\Big)^{\!2},\ 30\Big]}_{A_V}
\;\underbrace{-25\cdot\mathbb{1}\{|\Delta\varphi|>90^{\circ}\}}_{\text{FBR}}
$$

### A.2 损失对参数的总体结构

残差 $r_i = \hat{y}_i - y_i$，总损失 $L = \sum_i \rho(r_i)$，$\rho$ 为 Huber（$\delta=5$ dB）：

$$
\boxed{\ \frac{\partial L}{\partial \theta_j} = \sum_i \rho'(r_i)\cdot \frac{\partial \hat{y}_i}{\partial \theta_j}\ },
\qquad
\rho'(r) = \begin{cases} r, & |r| \le \delta \\ \delta\,\mathrm{sign}(r), & |r| > \delta \end{cases}
$$

FBR 是阶跃函数，梯度几乎处处为 0（分界点处取次梯度 0），代码中忽略。

### A.3 几何量的基础偏导

**距离**：

$$
\frac{\partial d}{\partial b_x} = -\frac{\Delta x}{d},
\qquad
\frac{\partial d}{\partial b_y} = -\frac{\Delta y}{d}
$$

**方位角**（$\mathrm{atan2}$ 求导后乘以 $\kappa$）：

$$
\frac{\partial \beta}{\partial b_x} = -\kappa\,\frac{\Delta y}{d^{2}},
\qquad
\frac{\partial \beta}{\partial b_y} = \kappa\,\frac{\Delta x}{d^{2}},
\qquad
\frac{\partial \Delta\varphi}{\partial \beta} = 1,
\qquad
\frac{\partial \Delta\varphi}{\partial \phi} = -1
$$

（缠绕点 $\Delta\varphi = \pm 180°$ 处不可微，取次梯度 1，测度为零不影响优化。）

**俯仰角**（记 $h' = h - 1.5$）：

$$
\frac{\partial \psi}{\partial h} = \kappa\,\frac{d}{d^{2} + h'^{2}},
\qquad
\frac{\partial \psi}{\partial d} = -\kappa\,\frac{h'}{d^{2} + h'^{2}},
\qquad
\frac{\partial \psi}{\partial b_x} = \frac{\partial \psi}{\partial d}\cdot\frac{\partial d}{\partial b_x}
\ \text{（$b_y$ 同理）},
\qquad
\frac{\partial \Delta\psi}{\partial \tau} = 1
$$

### A.4 路径损耗项

$$
\frac{\partial PL}{\partial p_0} = 1,
\qquad
\frac{\partial PL}{\partial n} = -10 \log_{10} d,
\qquad
\frac{\partial PL}{\partial d} = -\frac{10\,n}{d \ln 10}
$$

$$
\frac{\partial PL}{\partial b_x} = \frac{10\,n\,\Delta x}{d^{2}\ln 10},
\qquad
\frac{\partial PL}{\partial b_y} = \frac{10\,n\,\Delta y}{d^{2}\ln 10}
$$

### A.5 水平方向图项

tanh 平滑饱和形式：$A_H = -A_m \tanh\left(\dfrac{raw_H}{A_m}\right)$，
$raw_H = 12\left(\Delta\varphi/\phi_{bw}\right)^2$。
记 $s_H = \mathrm{sech}^2\left(\dfrac{raw_H}{A_m}\right) = 1 - \tanh^2\left(\dfrac{raw_H}{A_m}\right)$，
则 $\dfrac{\partial A_H}{\partial raw_H} = -s_H$（处处非零，无截断盲区）：

$$
\frac{\partial A_H}{\partial \Delta\varphi} = -s_H \cdot \frac{24\,\Delta\varphi}{\phi_{bw}^{2}}
$$

$$
\frac{\partial A_H}{\partial \phi} = s_H \cdot \frac{24\,\Delta\varphi}{\phi_{bw}^{2}},
\qquad
\frac{\partial A_H}{\partial \phi_{bw}} = s_H \cdot \frac{24\,\Delta\varphi^{2}}{\phi_{bw}^{3}}
$$

$$
\frac{\partial A_H}{\partial b_x} = -s_H \cdot \frac{24\,\Delta\varphi}{\phi_{bw}^{2}}\cdot\frac{\partial \beta}{\partial b_x},
\qquad
\frac{\partial A_H}{\partial b_y} = -s_H \cdot \frac{24\,\Delta\varphi}{\phi_{bw}^{2}}\cdot\frac{\partial \beta}{\partial b_y}
$$

主瓣/旁瓣区（$raw_H \ll 30$）：$s_H \approx 1$，与 3GPP 硬截断模型完全一致；
大角度区：$s_H$ 平滑衰减到 0，但始终非零，保留"超出边缘多远"的梯度信息。

### A.6 垂直方向图项

同理，$raw_V = 12\left(\Delta\psi/10^{\circ}\right)^2$，
$s_V = \mathrm{sech}^2(raw_V / A_m)$：

$$
\frac{\partial A_V}{\partial \Delta\psi} = -s_V \cdot \frac{24\,\Delta\psi}{100}
$$

$$
\frac{\partial A_V}{\partial \tau} = -s_V \cdot \frac{24\,\Delta\psi}{100},
\qquad
\frac{\partial A_V}{\partial h} = -s_V \cdot \frac{24\,\Delta\psi}{100}\cdot\frac{\partial \psi}{\partial h},
\qquad
\frac{\partial A_V}{\partial b_x} = -s_V \cdot \frac{24\,\Delta\psi}{100}\cdot\frac{\partial \psi}{\partial b_x}
\ \text{（$b_y$ 同理）}
$$

### A.7 8 个参数的汇总

$$
\frac{\partial \hat{y}}{\partial \theta} =
\begin{bmatrix}
\dfrac{\partial PL}{\partial b_x} + \dfrac{\partial A_H}{\partial b_x} + \dfrac{\partial A_V}{\partial b_x}
\\[2.2ex]
\dfrac{\partial PL}{\partial b_y} + \dfrac{\partial A_H}{\partial b_y} + \dfrac{\partial A_V}{\partial b_y}
\\[2.2ex]
s_H \cdot \dfrac{24\,\Delta\varphi}{\phi_{bw}^{2}}
\\[1.6ex]
s_H \cdot \dfrac{24\,\Delta\varphi^{2}}{\phi_{bw}^{3}}
\\[1.6ex]
-s_V \cdot \dfrac{24\,\Delta\psi}{100}
\\[1.6ex]
-s_V \cdot \dfrac{24\,\Delta\psi}{100}\cdot \kappa\dfrac{d}{d^{2}+h'^{2}}
\\[2.2ex]
-10 \log_{10} d
\\[1.6ex]
1
\end{bmatrix}
$$

所有分量对全部测量点有效（无截断特例），最终乘以 $\rho'(r_i)$ 累加，即得
$\nabla L(\theta)$。

### A.8 推导正确性的工程验证

- 与数值微分（中心差分）的对比是开发期的调试手段之一，解析梯度的引入使单次
  推断从分钟级降到秒级
- tanh 平滑饱和后方向图处处可微；仅剩的次梯度点是方位缠绕点（±180°）与
  FBR 阶跃（|Δφ|=90°），取单侧/零次梯度，Armijo 回溯保证损失单调不增
- $d$ 下限截断 1 m 处的不可微性同理忽略——测量点不会恰好压在基站 1 m 内
