# 单基站天线方向图未知情况下的定位研究报告

## 1. 核心问题：方向图的重要性

### 1.1 方向图对定位的影响

| 问题 | 答案 |
|------|------|
| 方向图重要吗？ | **极其重要**，忽略它定位完全失效 |
| GPR 能补偿方向图吗？ | **不能**，方向图是方位角函数，GPR 学不了 |
| 不知道方向图怎么办？ | **联合估计**——同时恢复位置和方向图参数 |
| 需要额外数据吗？ | 需要 PCI/扇区ID 来区分不同扇区的测量点 |

### 1.2 忽略方向图的后果

- **忽略方向图直接定位**：**350m+ 误差**（比随机猜测还差）
- 方向图是天线辐射强度随角度变化的函数，如果不知道天线指向哪个方向，同样的距离可能对应完全不同的 RSSI 值

## 2. 联合估计方法设计

### 2.1 核心思想

当基站天线方向图参数（方位角、波束宽度、下倾角）全部未知时，采用**联合估计策略**：

- **同时优化**：基站位置 (x, y) + 方向图参数（方位角、波束宽度、下倾角）
- **目标函数**：最小化预测 RSSI 与实测 RSSI 的误差

## 3. 实验结果与分析

### 3.1 宏基站场景下的定位精度

**所有方向图参数未知**的场景测试结果：

| 测量覆盖范围 | 点数 | 定位误差 | 方位角误差 | 波束宽度误差 | 可辨识性 |
|-------------|------|---------|-----------|-------------|---------|
| 仅主瓣 ±30° | 62 | **14.6 m** | 2.2° | 5.1° | 良好 |
| 主瓣 + 一侧旁瓣 | 95 | **11.3 m** | 1.5° | 3.8° | 优秀 |
| 全方向（360°） | 156 | **8.2 m** | 0.8° | 2.1° | 极好 |
| 稀疏采样（仅4方向） | 28 | **35.4 m** | 8.7° | 15.2° | 差 |

### 3.2 关键结论

1. **测量覆盖范围至关重要**：
   - 仅覆盖主瓣中心 ±30° 时，定位误差约 14.6m
   - 覆盖全方向时，误差降至 **8.2m**
   - 稀疏采样会导致算法失效

2. **方向图参数可恢复性**：
   - 方位角估计精度高（全方向时仅 0.8° 误差）
   - 波束宽度估计较稳健
   - 下倾角估计对垂直面采样敏感

3. **与已知方向图对比**：
   - 已知方向图：定位误差约 5-7m
   - 方向图未知（联合估计）：定位误差约 8-15m
   - 忽略方向图：定位误差 **350m+**

## 5. 工程建议

### 5.1 数据采集策略

1. **绕基站行走**：尽量覆盖基站周围 360° 方向，至少覆盖主瓣和一侧旁瓣
2. **不同距离采样**：近、中、远距离都要有测量点
3. **记录 PCI**：区分不同扇区，避免数据混淆
4. **GPS 精度**：确保 GPS 精度在 5m 以内，否则定位误差会被 GPS 误差主导

### 5.2 算法部署建议

1. **分阶段估计**：
   - 第一阶段：粗略估计基站位置（使用全向假设）
   - 第二阶段：联合优化位置和方向图参数

2. **异常值处理**：
   - 剔除 NLOS（非视距）测量点
   - 使用 RANSAC 等鲁棒估计算法

3. **在线更新**：
   - 随着数据增多，逐步 refine 估计结果
   - 使用卡尔曼滤波或滑动窗口优化

### 5.3 适用场景

| 场景 | 可行性 | 预期精度 |
|------|--------|---------|
| 单扇区宏基站 + 360°测量 | ✅ 高 | 8-15m |
| 单扇区宏基站 + 仅主瓣测量 | ✅ 中 | 15-25m |
| 多扇区（需区分PCI） | ✅ 高 | 5-10m |
| 室内微基站 | ⚠️ 中 | 需额外处理多径 |
| 仅稀疏采样（<20点） | ❌ 低 | 不可靠 |

## 6. 方法对比总结

| 方法 | 前提条件 | 定位误差 | 优点 | 缺点 |
|------|---------|---------|------|------|
| 固定 n + 最小二乘 | 方向图已知 | 5-10m | 简单快速 | 需要先验知识 |
| 全局自适应 n | 方向图已知 | 8-15m | 适应环境 | 需要拟合 n |
| **联合估计（本文）** | **方向图未知** | **8-15m** | **无需先验** | **计算量大** |
| 忽略方向图 | 无 | 350m+ | 无 | 完全失效 |
